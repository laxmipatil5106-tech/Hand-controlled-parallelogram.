# ✋ Hand-Controlled Parallelogram
A real-time computer vision project that uses **hand gestures** to control and interact with a visual parallelogram using a webcam.
The project uses **Python, OpenCV, and MediaPipe** to detect hand landmarks and respond to hand movements in real time.
## Features
* Real-time webcam interaction
* Hand landmark detection
* Finger tracking
* Gesture-controlled parallelogram
* Dynamic parallelogram interaction
* Pastel visual effects
* Real-time processing
## 🛠️ Technologies Used
* **Python**
* **OpenCV** – computer vision and webcam processing
* **MediaPipe** – hand landmark detection
* **NumPy** – numerical operations
## How It Works
1. The webcam captures live video.
2. MediaPipe detects the user's hand and its landmarks.
3. Finger positions are tracked in real time.
4. The detected finger positions are used to control the parallelogram.
5. OpenCV processes and renders the visual effect on the live camera feed.
